# Award Network Hub

I want to build a professional mobile application called TIAN (The International Award Network).



TIAN is an independent global community platform for participants, Award Leaders, Award Centres, assessors, alumni, and universities connected to The Duke of Edinburgh's International Award.



Your role is to act as a senior UI/UX designer, product designer, and full-stack developer.



Do NOT build the entire app at once.



First, create a beautiful, modern, mobile-first design system with reusable components.



The design should be inspired by the simplicity of WhatsApp and Messenger, but it must have its own unique identity.



Use:



- Navy blue as the primary colour

- White background

- Green accents

- Gold highlights

- Rounded corners

- Smooth animations

- Clean typography

- Premium appearance



Build only these screens first:



1. Welcome Screen

2. Create Account

3. Account Setup

4. Profile Setup

5. Home Screen



The Home Screen should include a bottom navigation bar with:



- Home

- Community

- Status

- Chats

- Profile



Do not build messaging, communities, events, or premium features yet.



Create the project using a scalable architecture so more features can easily be added later.



Think like you're designing the next LinkedIn or Discord for the International Award community.



Every screen should feel polished, responsive, modern, and production-ready.
